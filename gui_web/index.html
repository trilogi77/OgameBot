📢 Guía para configurar el bot de Telegram
  1. Busca a @BotFather en Telegram e inicia una conversación (clic en Iniciar o envía /start).
  2. Envía el comando /newbot y sigue las instrucciones para asignarle un nombre y un nombre de usuario a tu bot. Al finalizar, @BotFather te dará el Token HTTP API (ej: 123456789:ABCdef...). Pégalo arriba.
  3. Busca el nombre de usuario de tu nuevo bot en Telegram, abre un chat con él y pulsa en Iniciar / Start. (Este paso es obligatorio para permitir que el bot te mande mensajes).
  4. Para obtener tu ID de chat personal, busca a @userinfobot en Telegram, inicia un chat y este te responderá automáticamente con tu Id numérico (ej: 987654321). Pégalo en el campo de ID arriba.
  5. Haz clic en Guardar Cambios en la interfaz. ¡Tu bot de Telegram ya estará listo para notificarte ataques en tiempo real!
