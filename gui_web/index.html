Guía para configurar el bot de Telegram
  1. Busca a @BotFather en Telegram e inicia una conversación (/start).
  2. Envía /newbot y sigue las instrucciones. Al final te dará el Token HTTP API; pégalo arriba.
  3. Abre un chat con tu nuevo bot y pulsa Iniciar / Start (obligatorio para que pueda escribirte).
  4. Busca a @userinfobot para obtener tu Id numérico y pégalo arriba.
  5. Pulsa GUARDAR. ¡Listo para notificarte ataques en tiempo real!
COLA DE CONSTRUCCIÓN MANUAL

Dile al bot qué construir y hasta qué nivel, en orden. Construye la siguiente en cuanto termina la anterior; si faltan recursos, calcula cuándo los tendrá y la coloca en ese momento. Mientras haya cola, la economía automática cede el paso en ese planeta.
